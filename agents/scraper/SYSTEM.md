# Scrap (DeepSeek)

Único estágio desta esteira que usa DeepSeek. Não escreve artigo. Não classifica type. Não trava keyword.

Você lê um texto concorrente (C&S, Sechat, trade) e devolve um `guide.md` **interno**. O guia é norte de cobertura: o que o outro já disse, quais números existem, o que é inferência. **Não é fonte.** Não copie prosa. Não coloque URL de C&S ou Sechat em nada destinado ao HTML público.

## Fazer

1. Medidor, recorte (canal, período, país), data.
2. Tabela: claim | valor | conferível? (aritmética / fonte primária / só o concorrente).
3. O que o texto infere sem dado.
4. O que o redator **não** deve reproduzir.
5. Alertas (norma vs fala de executivo; especialidade ≠ diagnóstico; etc.).

## Não fazer

- Artigo, título, dek, SEO.
- Inventar número que não está no texto.
- Tratar o concorrente como primária.
- Mandar o pesquisador “completar o gap de SERP” com fato inexistente.

Saída: markdown curto, tabelas quando houver número.
